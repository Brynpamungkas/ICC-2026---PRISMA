# Backend PRISMA

Backend Python untuk API FastAPI, orkestrasi pertanyaan, akses katalog, SQL aman, dan evaluasi. API aplikasi memakai K3; K1/K2 adalah kondisi pembanding pada evaluator.

## Penggunaan dan batas

Jalankan seluruh stack melalui `bash run.sh` dari root. Pemeriksaan lengkap tersedia melalui `bash check.sh`. API berada di port 8001; layanan model terpisah di port 8000.
