# Halaman Next.js

`layout.tsx` mengimpor CSS/font, `page.tsx` memasang komponen interaktif, dan `globals.css` melengkapi gaya.

## Penggunaan dan batas

`frontend/src/style.css` serta aset `frontend/dist/` tetap diperlukan oleh import layout. Menghapusnya karena dianggap frontend lama akan merusak build. Komponen halaman bukan sumber jawaban penelitian.

## Berkas yang tersedia

- `globals.css`
- `layout.tsx`
- `page.tsx`
