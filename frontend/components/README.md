# Komponen interaksi PRISMA

Panel aplikasi dan tes interaksinya: input, status layanan, loading, keputusan, klarifikasi, katalog dan log.

## Penggunaan dan batas

Pertahankan semua kandidat TANYA serta alur pilih → konfirmasi → JAWAB dari API. Angka diformat Indonesia tanpa mengubah nilai/skala; NULL tidak diganti nol. Tes komponen memakai fixture/mock, bukan bukti eksekusi model asli.
