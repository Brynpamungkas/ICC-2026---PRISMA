# Sumber dan komponen pihak ketiga

Data BPS: daftar sumber, metadata dan manifest di `data/raw_bps/`; angka tidak dibuat untuk keperluan rilis. Lisensi/ketentuan pemakaian mengikuti sumber resminya.

Model Qwen: repository/revision/hash pada `release/profile.json`. Bobot tidak dimasukkan Git. Lisensi model dan tokenizer mengikuti repository resmi Qwen yang diunduh.

llama.cpp, vLLM, Next.js dan dependensi: lisensi mengikuti proyek upstream/paket. Folder hasil instalasi dan binary model server tidak dimasukkan Git. File font/brand milik proyek dipertahankan dari versi sumber.

Ekspor ini tidak menetapkan lisensi baru atas karya tim atau komponen pihak ketiga. Tidak menambahkan klaim hak cipta/izin yang belum ditetapkan pemilik.
