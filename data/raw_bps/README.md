# Sumber mentah BPS

CSV resmi yang digunakan ETL beserta manifest dan catatan sumber. Tidak semua periode pada judul berkas otomatis menjadi cakupan semua indikator.

## Penggunaan dan batas

Periksa `manifest.yaml`, `sumber.md` dan metadata sebelum memakai angka. Snapshot input, checksum dan aturan ETL harus konsisten. Contoh manifest adalah format, bukan bukti pengunduhan dataset baru.
