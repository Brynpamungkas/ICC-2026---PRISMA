# Bukti lingkungan NVIDIA historis

Inventaris mesin tim, pemeriksaan versi/GPU, smoke model dan hash bobot yang diekspor dari source M5.

## Penggunaan dan batas

Bukti ini berasal dari mesin NVIDIA tim, bukan laptop CPU ini atau pengujian ulang paket rilis. Snapshot penggunaan VRAM bukan otomatis peak VRAM setiap run test atau bukti kelayakan GPU 4 GB.
