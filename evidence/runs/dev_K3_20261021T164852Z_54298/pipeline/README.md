# Trace pipeline historis

JSONL trace tahapan, eksekusi/voting dan korelasi run yang benar-benar direkam oleh implementasi CPU.

## Penggunaan dan batas

Urutan event dan run_id harus dibaca apa adanya. Cocokkan referensi transport, hash dan record induk. Trace adalah bukti historis, bukan alasan mengubah hasil atau konfigurasi test.
