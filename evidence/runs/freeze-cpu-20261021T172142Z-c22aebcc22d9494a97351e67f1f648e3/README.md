# Manifest freeze CPU historis

Catatan persetujuan, dev run, tau serta hash konfigurasi/data/kode sumber yang dibekukan pada penelitian CPU.

## Penggunaan dan batas

Manifest mengacu ke versi historis, bukan commit repository rilis baru. Jangan mengganti identitas/hash atau mengklaim freeze ini berlaku otomatis pada inferensi test baru.

## Berkas yang tersedia

- `local-commit-proposal.json`
- `local.cpu.before.yaml`
- `manifest.json`
- `post-commit-test-readiness.json`
- `post-commit-verification.json`
- `test-readiness-check.json`
- `verification.json`
