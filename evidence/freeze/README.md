# Salinan freeze historis GPU

Salinan metadata/hasil kalibrasi atau evaluasi yang tersedia pada jalur freeze sumber GPU. Hubungannya harus diperiksa terhadap manifest dev/test asli.

## Penggunaan dan batas

Keberadaan folder freeze bukan bukti otomatis freeze test lengkap. Repository rilis mempunyai commit baru; jangan mengganti commit/hash historis atau menganggap freeze lama membekukan kode rilis ini.
