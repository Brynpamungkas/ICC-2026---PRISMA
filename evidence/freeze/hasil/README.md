# Metrik salinan freeze

JSON metrik yang memang tersimpan pada folder freeze sumber. Ini salinan historis yang perlu dibaca bersama run dan manifest asalnya.

## Penggunaan dan batas

Untuk tabel paper gunakan sumber run yang teridentifikasi dan periksa konsistensi pembilang, penyebut dan versi checker. Jangan mencampur salinan dari run berbeda.
