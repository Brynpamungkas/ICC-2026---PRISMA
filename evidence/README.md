# Arsip bukti penelitian

Salinan bukti yang sudah ada pada sumber; bukan hasil eksperimen yang dijalankan saat menulis README. Manifest asal tetap menunjukkan commit, konfigurasi, data dan path historisnya.

## Penggunaan dan batas

Checksum setiap artefak asli tercatat pada `release/source_manifest.json`. README di pohon ini merupakan panduan rilis tambahan, bukan artefak keluaran run dan bukan bagian bukti empiris asli. Run terputus tidak dihapus atau digabung diam-diam ke run lengkap.
